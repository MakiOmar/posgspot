عنوان المشروع:
نظام إدارة وبيع الحسابات الرقمية وبطاقات الهدايا - Games Spot Accounts

الوصف:
نظام ويب متخصص لإدارة مخزون حسابات ألعاب PlayStation الرقمية والاشتراكات وبطاقات الهدايا وبيعها. يعمل جنبًا إلى جنب مع نظام نقاط البيع والمتجر الإلكتروني، ويتولى تسليم الطلبات الرقمية آليًا ومتابعة التكلفة والأرباح بدقة.

أبرز المميزات:
- مخزون لكل حساب حسب المنصة (PS4 / PS5) ونوع البيع (Primary / Secondary / Offline)، مع اختيار الحساب المناسب تلقائيًا عند كل عملية بيع.
- إدارة الألعاب والأسعار وحالات البيع، والاشتراكات (PS Plus)، وبطاقات الهدايا وتصنيفاتها.
- ربط مع مورد بطاقات الهدايا Next Load لشراء الأكواد آليًا، مع مراعاة توفر المخزون لدى المورد.
- تسليم آلي للطلبات الرقمية القادمة من المتجر الإلكتروني عبر واجهة API آمنة.
- إدارة التجار ومدفوعاتهم، والأسعار الخاصة، وملفات المتاجر وقيود البيع، وأوامر الشراء.
- لوحة تحكم بمؤشرات مالية، منها تكلفة الأصول غير المباعة والمتبقية في المخزون.
- تقارير توضح منفذ كل عملية، وتصدير سجلات المبيعات إلى Excel.
- متابعة صيانة الأجهزة، وإتاحة تتبعها للعملاء برقم الهاتف، وتقييمات العملاء.
- أدوار وصلاحيات تفصيلية، وسجل لنشاط المستخدمين، ونسخ احتياطي تلقائي إلى Google Drive، وتخزين مؤقت لتسريع الأداء.

التقنيات المستخدمة:
Laravel (PHP) - MySQL - Redis - REST API (Laravel Sanctum) - Docker
