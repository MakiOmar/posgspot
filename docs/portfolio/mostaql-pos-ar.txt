عنوان المشروع:
نظام نقاط بيع (POS) متكامل ومتجر إلكتروني لسلسلة متاجر ألعاب - Games Spot

الوصف:
منظومة متكاملة لإدارة المبيعات والمخزون لسلسلة متاجر Games Spot بفروعها المتعددة. تربط نقاط البيع داخل الفروع بمتجر إلكتروني حديث ثنائي اللغة (عربي / إنجليزي)، وتعتمد على قاعدة بيانات واحدة، فتبقى الأسعار والمخزون والطلبات متطابقة بين الفروع والموقع لحظة بلحظة.

أبرز المميزات:
- إدارة المبيعات والمشتريات والمخزون لعدة فروع، مع أدوار وصلاحيات تفصيلية للموظفين.
- وحدات لصيانة الأجهزة ومتابعة حالتها، والبيع بالتقسيط، وإدارة علاقات العملاء (CRM).
- متجر إلكتروني سريع ومُهيأ لمحركات البحث (SEO)، يعرض المنتجات ومدى توفرها في كل فرع.
- دفع إلكتروني عبر Fawry و Geidea، والدفع عند الاستلام مع إمكانية قصره على عملاء محددين.
- ربط مع شركة الشحن Bosta، ومناطق وأسعار شحن مرنة، واستلام من الفرع.
- بيع المنتجات الرقمية (ألعاب PlayStation وبطاقات الهدايا) وتسليمها تلقائيًا بعد الدفع عبر الربط مع نظام الحسابات.
- حسابات عملاء مع تأكيد البريد الإلكتروني وتسجيل الدخول بجوجل وفيسبوك، ونقاط مكافآت، وأكواد خصم، وقائمة أمنيات، وتقييمات للمنتجات.
- مساعد دعم فني بالذكاء الاصطناعي، وخدمات "بيع لنا" وطلب منتج غير متوفر وتتبع الطلبات والصيانة.
- لوحة تحكم لإدارة المتجر: بناء الصفحة الرئيسية بالسحب والإفلات، والقوائم، والبنرات، والترجمات، وإعدادات الدفع والشحن.
- تنبيهات فورية للموظفين بالطلبات الجديدة عبر الإشعارات والبريد الإلكتروني.

التقنيات المستخدمة:
Laravel (PHP) - MySQL - Redis - Qwik City (TypeScript) - React Native / Expo - Docker - Traefik - Cloudflare
